
# 대시보드 패널에 로그 알림 띄우기

[ Server-Sent Events(SSE) ]
--> SSE + 알림음 + 화면 배지(Badge)

1. Toast: 우측 상단 알림

2. 이벤트로그 메뉴- 빨간 배지(📋이벤트로그 조회 -> 🔴이벤트로그 조회)

3. 알림음: ding.mp3재생

4. 테이블의 행 강조: 옅은 노란색으로 강조 -> 다시 원래대로

5. 브라우저 Notification: 새 로그가 발생했습니다. <-브라우저 권한을 허용하면 가능
