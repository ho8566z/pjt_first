 아이디어 소개

다음은 프로젝트의 아이디어와 선정 배경입니다.
최근 CCTV와 드론의 활용이 확대되면서 다양한 분야에서 영상 관제가 이루어지고 있습니다.

하지만 기존 관제 방식은 관리자가 여러 화면을 지속적으로 확인해야 하므로 피로도가 높고, 이상 상황을 놓칠 가능성이 있습니다.
또한 실종자나 수배자와 같은 특정 인물을 사람이 직접 확인하는 방식은 많은 시간과 인력이 필요해 긴급 상황에 신속하게 대응하기 어렵습니다.

저희는 이러한 문제를 해결하기 위해 AI를 활용한 영상 분석 기술을 관제 시스템에 적용하고자 하였습니다.

본 프로젝트의 목표는 CCTV와 드론 영상을 실시간으로 분석해 사람을 자동으로 탐지하고 추적한 뒤, 등록된 대상 인물을 식별해 관리자에게 즉시 알림을 제공하는 것입니다.

이를 통해 관제 효율을 높이고 보다 빠른 대응이 가능한 시스템을 구현하고자 하였습니다.

 서비스 구성도

먼저 서비스 구성도입니다.
본 시스템은 CCTV와 드론으로부터 실시간 영상을 입력받아 Flask 서버에서 처리하고, AI 모델을 통해 객체 탐지와 얼굴 식별을 수행하도록 구성하였습니다.

AI 분석 결과는 이벤트 정보와 함께 JSON 형태로 저장되며, 웹 관제 시스템에서는 이를 실시간으로 확인할 수 있습니다.
또한 관리자는 하나의 웹 환경에서 실시간 관제뿐 아니라 회원 관리, 카메라 관리, 대상 인물 관리, 이벤트 로그 조회, 사용자 로그 조회 기능까지 통합적으로 사용할 수 있도록 설계하였습니다.
이와 같이 영상 입력부터 AI 분석, 데이터 저장, 웹 서비스까지 하나의 흐름으로 연결되는 구조를 구성하였습니다.

 데이터 수집 및 활용 절차

다음은 데이터 수집 및 활용 절차입니다.
먼저 CCTV와 드론에서 실시간 영상을 입력받으면 AI가 영상 속 사람을 탐지합니다.

객체 탐지에는 YOLOv8을 적용해 사람의 위치를 빠르게 검출하고, 탐지된 객체는 BoT-SORT를 이용해 동일한 Track ID를 유지하며 지속적으로 추적합니다.
이후 추적 중인 객체의 얼굴을 InsightFace로 분석해 등록된 대상 인물과 비교합니다.

등록된 대상 인물로 확인되면 이벤트를 생성하고, 발생 시간과 위치 정보, 이벤트 이미지를 함께 저장합니다.

생성된 이벤트는 웹 관제 화면으로 전달되어 관리자가 별도의 새로고침 없이 실시간으로 확인할 수 있도록 구현하였습니다.
이러한 과정을 통해 사람의 탐지부터 추적, 얼굴 식별, 이벤트 생성까지 모두 자동으로 수행하도록 구현하였습니다.

 API 명세서

다음은 API 명세서입니다.
시스템의 각 기능은 REST 방식의 API로 구현해 화면과 서버가 데이터를 주고받도록 구성하였습니다.

회원 관리 API는 회원 등록과 조회, 수정, 삭제 기능을 제공하며,

카메라 관리 API는 카메라 등록과 삭제, 위치 정보를 관리합니다.

대상 인물 관리 API는 얼굴 정보 등록과 수정, 삭제 기능을 제공합니다.
또한 이벤트 로그 API와 사용자 로그 API를 통해 로그 조회와 엑셀 다운로드 기능을 제공하도록 구현하였습니다.

특히 실시간 이벤트 알림은 SSE(Server-Sent Events)를 이용해 새로운 이벤트가 발생하면 서버가 클라이언트에 즉시 알림을 전송하도록 구현하였습니다.
이를 통해 화면을 새로고침하지 않아도 새로운 이벤트를 실시간으로 확인할 수 있습니다.

 주요 함수

다음은 주요 함수에 대해 설명드리겠습니다.
먼저 카메라 관리 함수입니다.
카메라를 등록하면 실시간 카메라 또는 영상 파일을 생성하고, 해당 카메라의 위치 좌표를 함께 저장합니다.
이를 통해 여러 대의 카메라를 하나의 시스템에서 효율적으로 관리할 수 있도록 구현하였습니다.

다음은 회원 관리 함수입니다.
회원 생성 시 사용자 역할에 따라 권한을 자동으로 부여하며, 관리자는 회원의 권한 변경과 관리를 수행할 수 있도록 구현하였습니다.

다음은 AI 분석 함수입니다.
객체 추적 함수에서는 YOLO와 BoT-SORT를 이용해 사람을 탐지하고 추적하며, 동일한 객체를 지속적으로 관리합니다.

얼굴 식별 함수에서는 등록된 대상과 얼굴 특징을 비교해 동일 인물 여부를 판단합니다.
또한 이미 식별된 대상은 일정 시간 동안 재분석하지 않도록 해 불필요한 연산을 줄이고 처리 성능을 향상시켰습니다.

다음은 이벤트 로그 관리 함수입니다.
대상 인물이 식별되면 이벤트 로그를 생성해 발생 시간, 위치 정보, 이미지 경로를 저장합니다.
또한 이벤트 조회와 엑셀 다운로드 기능을 제공해 관리자가 이벤트 이력을 효율적으로 관리할 수 있도록 구현하였습니다.

마지막은 실시간 알림 기능입니다.
Server-Sent Events, 즉 SSE를 이용해 새로운 이벤트가 발생하면 서버가 클라이언트에 즉시 알림을 전송하도록 구현하였습니다.

사용자는 화면을 새로고침하지 않아도 새로운 이벤트를 확인할 수 있으며, 이벤트 목록과 알림이 자동으로 갱신됩니다.

이처럼 본 시스템은 영상 수집부터 AI 분석, 데이터 저장, 실시간 알림, 웹 서비스까지 하나의 흐름으로 통합해 실시간 관제가 가능하도록 구현하였습니다.
이어서 프로젝트 시연을 진행하겠습니다.

 프로젝트 성과

먼저 프로젝트 성과입니다.
이번 프로젝트를 통해 AI 객체 탐지와 얼굴 식별 기술을 웹 기반 관제 시스템에 적용해, 사람을 실시간으로 탐지하고 추적하는 시스템을 구현하였습니다.
또한 CCTV와 드론 영상을 하나의 시스템에서 통합 관리하고, 대상 인물 식별부터 이벤트 생성, 실시간 알림, 로그 관리까지 하나의 흐름으로 자동화하였습니다.

이를 통해 관리자는 여러 화면을 지속적으로 확인하지 않아도 이벤트를 빠르게 인지하고 대응할 수 있어 관제 효율을 높일 수 있었습니다.

개발 과정에서는 Flask 기반 웹 시스템 구축뿐 아니라 YOLOv8, BoT-SORT, InsightFace와 같은 AI 기술을 직접 적용하며 AI와 웹 서비스를 연계하는 경험을 쌓을 수 있었습니다.
또한 Git을 활용한 협업과 역할 분담을 통해 팀원 간 협업 능력과 문제 해결 능력도 함께 향상시킬 수 있었습니다.

 아쉬운 점

다음은 프로젝트를 진행하며 느낀 아쉬운 점입니다.
프로토타입 형태로 개발하다 보니 다양한 환경에서 충분한 성능 검증을 진행하지 못한 점이 있었습니다.

또한 얼굴 인식에 사용할 수 있는 데이터의 양이 제한적이어서 다양한 환경에서의 인식 정확도를 충분히 검증하지 못했습니다.
이와 함께 실제 대규모 관제 환경에서의 성능과 안정성까지는 확인하지 못한 점도 프로젝트의 한계였습니다.

 개선 계획

다음은 개선 계획입니다.
먼저 다양한 환경에서 수집한 데이터를 추가해 AI 모델의 정확도와 안정성을 향상시킬 계획입니다.

또한 모델 최적화를 통해 분석 속도를 개선하고, 대용량 영상에서도 안정적으로 처리할 수 있도록 성능을 보완할 수 있습니다.

사용자 인터페이스도 지속적으로 개선해 관리자가 보다 직관적이고 편리하게 시스템을 사용할 수 있도록 발전시킬 수 있습니다.

 향후 확장 방향

마지막으로 향후 확장 방향입니다.
이번 프로젝트는 프로토타입 형태로 개발되었지만 다양한 방향으로 확장할 수 있습니다.

먼저 CCTV뿐 아니라 다양한 IoT 센서와 연동해 화재나 침입과 같은 복합 상황을 함께 분석하는 스마트 관제 시스템으로 발전시킬 수 있습니다.
또한 클라우드 환경을 적용하면 여러 지역의 카메라를 하나의 시스템에서 통합 관리해 대규모 관제 환경에서도 효율적으로 운영할 수 있습니다.

AI 모델의 정확도를 지속적으로 개선하고 학습 데이터를 확대한다면 사람뿐 아니라 다양한 객체까지 인식하는 더욱 고도화된 지능형 관제 시스템으로 발전할 수 있을 것으로 기대합니다.

다만 이러한 내용은 실제 개발 계획이라기보다, 본 프로젝트를 기반으로 한 확장 가능성을 제시한 것입니다.
이상으로 지능형 영상 분석 기반 AI 관제 시스템 발표를 모두 마치겠습니다.
