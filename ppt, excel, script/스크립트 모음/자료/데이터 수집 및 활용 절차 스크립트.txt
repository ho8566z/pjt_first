데이터 수집 및 활용 절차

1. 프로젝트 전체 흐름

다음으로 데이터가 수집되고 활용되는 전체 과정을 설명드리겠습니다.

저희 시스템의 전체 과정은 크게 데이터 수집, 데이터 전처리, AI 분석, 결과 저장, 서비스 활용의 다섯 단계로 구성됩니다.
먼저 드론이나 CCTV 영상, 대상자 얼굴 이미지, 카메라 위치 정보 등을 수집합니다.
수집된 영상은 OpenCV를 통해 프레임 단위로 처리한 뒤 AI 모델에 전달됩니다.
AI 분석 단계에서는 사람을 탐지하고, 같은 사람의 이동을 추적한 다음 등록 대상자와 얼굴을 비교합니다.
분석 결과는 탐지 시간, 위치, 대상자 ID, 캡처 이미지 등의 형태로 저장됩니다.
마지막으로 저장된 결과를 실시간 관제 화면, 지도, 경고 표시, 이벤트 로그와 대시보드 통계에 활용합니다.


2. AI 분석 단계 강조

앞에서 전체적인 데이터 흐름을 설명드렸다면, 여기서는 그중 핵심인 AI 분석 단계를 조금 더 자세히 살펴보겠습니다.

저희 시스템에서는 한 가지 AI 모델만 사용하는 것이 아니라, 서로 다른 역할을 가진 세 가지 모델을 연결했습니다.
첫 번째는 영상에서 사람을 찾는 YOLO,
두 번째는 동일한 사람을 계속 따라가는 BoT-SORT,
세 번째는 등록 대상자와 얼굴을 비교하는 InsightFace입니다.
이제 각 모델이 어떤 역할을 하고, 프로젝트에 맞게 어떻게 적용했는지 순서대로 설명드리겠습니다.


3. 사전 학습 AI 모델 활용 방식

저희는 AI 모델을 처음부터 새로 학습시키지는 않았습니다.

이미 학습된 공개 모델을 사용하고, 프로젝트 목적에 맞게 설정값과 처리 방식을 조정했습니다.
YOLO는 여러 종류의 객체 중 사람만 탐지하도록 설정했고, BoT-SORT는 여러 카메라의 추적 정보가 섞이지 않도록 카메라별로 분리했습니다.
InsightFace는 등록된 얼굴과 실시간 얼굴의 특징값을 비교하고, 유사도가 일정 기준 이상이면 동일한 대상자로 판단하도록 구성했습니다.
또한 한 사람의 얼굴 사진을 여러 장 등록할 경우 특징값의 평균을 저장하고, 얼굴 인식을 비동기로 실행해 영상 지연을 줄였습니다.
즉, 학습된 모델 자체를 변경한 것이 아니라, 모델의 설정과 모델 사이의 연결 방식을 프로젝트에 맞게 커스터마이징했습니다.


4. YOLO 사람 탐지

첫 번째 모델은 YOLO입니다.

YOLO는 영상 속 객체의 위치를 빠르게 찾아내는 객체 탐지 모델입니다.
일반적인 YOLO 모델은 사람뿐만 아니라 자동차, 자전거, 동물 등 다양한 객체를 탐지할 수 있습니다.
하지만 저희 프로젝트의 목적은 사람을 추적하는 것이기 때문에, classes=[0] 설정을 적용하여 사람 클래스만 탐지하도록 제한했습니다.
또한 탐지 신뢰도는 0.4, IoU 값은 0.55, 입력 이미지 크기는 640으로 설정했습니다.
이렇게 탐지된 사람의 위치 좌표와 영역은 다음 단계인 BoT-SORT로 전달됩니다.
정리하면 YOLO는 전체 영상에서 분석할 사람의 영역을 먼저 찾아주는 1차 탐지 역할을 수행합니다.


5. BoT-SORT 동일 인물 추적

두 번째는 BoT-SORT입니다.

YOLO는 각 프레임에서 사람이 어디에 있는지는 찾아주지만,
이전 프레임의 사람과 현재 프레임의 사람이 같은 사람인지는 지속적으로 관리하기 어렵습니다.
BoT-SORT는 탐지된 사람에게 Track ID라는 임시 번호를 부여합니다.
사람이 이동하더라도 같은 사람이라고 판단되면 동일한 Track ID를 유지하기 때문에, 영상 안에서 이동 경로를 계속 추적할 수 있습니다.
저희 시스템에서는 카메라마다 별도의 추적기를 생성했습니다. 이를 통해 서로 다른 카메라의 Track ID와 추적 정보가 섞이지 않도록 구성했습니다.
또한 Track ID별로 식별 결과를 임시 저장하여, 매 프레임마다 얼굴 인식을 반복하지 않도록 했습니다.
즉, BoT-SORT는 YOLO가 찾은 사람을 프레임별로 연결하여 같은 사람을 계속 따라가는 역할을 수행합니다.


6. InsightFace 얼굴 식별

세 번째는 InsightFace입니다.

InsightFace는 사람의 얼굴을 숫자로 이루어진 특징 벡터로 변환하는 얼굴 인식 모델입니다.
먼저 등록 대상자의 얼굴에서 특징 벡터를 추출하여 NPZ 파일에 저장합니다.
실시간 영상에서 사람이 탐지되면 해당 사람 영역 안의 얼굴 특징값을 다시 추출하고, 등록된 특징값과 유사도를 비교합니다.
저희 시스템에서는 유사도가 0.45 이상일 경우 등록된 대상자와 동일한 사람으로 판단했습니다.
일치하는 대상자가 확인되면 대상자 ID와 유사도 결과를 화면에 표시합니다.
정리하면 InsightFace는 단순히 얼굴이 있는지를 찾는 것이 아니라, 탐지된 사람이 등록 대상자인지를 최종적으로 확인하는 역할을 수행합니다.


7. 추가 가공 및 시스템 연결

세 가지 모델을 사용했다고 해서 바로 실시간 관제 시스템이 완성되는 것은 아닙니다.

저희는 모델의 결과를 안정적으로 사용하기 위해 추가적인 처리 로직을 적용했습니다.
먼저 한 명의 대상자에게 여러 장의 얼굴 사진을 등록할 경우, 각 사진에서 추출한 특징값의 평균을 계산해 저장했습니다.
한 장의 사진만 사용하는 것보다 여러 각도와 표정의 정보를 반영할 수 있어 비교 결과가 안정적입니다.
또한 얼굴 인식은 시간이 오래 걸릴 수 있기 때문에 별도의 작업으로 비동기 처리했습니다.
신원이 아직 확인되지 않은 사람은 짧은 주기로 다시 확인하고, 이미 식별된 사람은 확인 주기를 길게 설정하여 중복 연산을 줄였습니다.
최종적으로 확인된 대상자의 ID, 발견 시간, 카메라 위치, 캡처 이미지를 이벤트 로그에 저장하고, 대시보드와 지도에 표시했습니다.
전체 흐름은 영상 입력 → YOLO 탐지 → BoT-SORT 추적 → InsightFace 식별 → 위치 표시·경고·로그 저장 순서입니다.


8. 문제점 및 해결 방안

모델을 실제 영상에 적용하면서 몇 가지 문제도 발생했습니다.

첫 번째는 원거리 촬영이나 사람 가림으로 인해 YOLO가 사람을 놓치는 문제입니다.
이를 해결하기 위해 탐지 신뢰도와 입력 크기를 조정하고, 카메라의 해상도와 촬영 각도를 개선할 수 있도록 했습니다.

두 번째는 사람이 겹치거나 화면에서 사라졌다가 다시 등장할 때 Track ID가 변경되는 문제입니다.
카메라별 추적기를 분리하고, 얼굴 인식 결과를 활용해 대상자를 다시 확인하도록 구성했습니다.

세 번째는 측면 얼굴이나 작은 얼굴, 어두운 환경, 마스크와 안경 등으로 인해 얼굴 인식 성능이 낮아지는 문제입니다.
여러 각도의 얼굴 사진을 등록하고, 특징 벡터의 평균을 사용했으며 일정 시간이 지나면 다시 얼굴을 확인하도록 했습니다.

마지막으로 모든 분석을 동시에 수행하면 영상이 지연될 수 있습니다. 이를 해결하기 위해 얼굴 인식을 비동기 처리하고, 이미 식별된 사람은 분석 주기를 늘려 중복 분석을 줄였습니다.


9. 모델 사용 결과

마지막으로 모델 적용 결과입니다.

YOLO는 사람만 탐지하도록 설정하여 불필요한 객체 분석을 줄였습니다.
BoT-SORT는 사람마다 Track ID를 부여해 이동하는 동일 인물을 지속적으로 추적했습니다.
InsightFace는 등록된 얼굴과 실시간 얼굴을 비교하여 대상자를 식별했습니다.
또한 비동기 처리와 분석 주기 조절을 적용하여 중복 연산과 영상 지연을 줄였습니다.
결과적으로 저희 시스템은 사람 탐지, 동일 인물 추적, 대상자 식별, 실시간 관제 결과 제공까지 하나의 흐름으로 연결할 수 있었습니다.
