사용 툴 및 개발 환경

1. 전체 개발 환경

먼저 저희 프로젝트에서 사용한 개발 환경입니다.

운영체제는 Windows 10, 주요 개발 언어는 Python 3.12를 사용했습니다.
웹 시스템은 Python 기반의 Flask로 구현했으며, 화면 구성에는 Jinja2, HTML, CSS, JavaScript를 사용했습니다.
영상 처리와 AI 분석에는 OpenCV, YOLO, InsightFace, Torch, ONNX Runtime을 활용했습니다.
데이터는 별도의 데이터베이스 서버 대신 JSON 파일로 관리했고, 얼굴의 특징값은 계산에 적합한 NPZ 파일로 저장했습니다.
또한 팀원 간 코드 공유와 협업을 위해 Git, GitHub, Slack을 사용했습니다.
버전 정보는 화면에 표시된 내용을 참고해 주시면 됩니다.

2. 개발 환경 및 시스템 구조

다음은 각 기술이 시스템에서 어떻게 연결되는지를 나타낸 구조입니다.

사용자가 웹 화면에서 기능을 실행하면, Flask 서버가 요청을 받아 필요한 데이터를 처리합니다.
실시간 영상이나 영상 파일이 들어오면 OpenCV가 영상을 프레임 단위로 읽어옵니다.
이후 AI 분석 영역에서 YOLO가 사람을 탐지하고, BoT-SORT가 탐지된 사람의 이동을 추적합니다.
마지막으로 InsightFace가 등록된 대상자의 얼굴과 비교하여 신원을 확인합니다.
분석 결과는 JSON과 NPZ 파일에 저장되고, 대시보드·지도·이벤트 로그와 같은 관제 화면에 전달됩니다.
즉, 각각의 기술을 따로 사용한 것이 아니라, 웹 화면부터 AI 분석과 결과 저장까지 하나의 흐름으로 연결한 시스템이라고 볼 수 있습니다.

3. 영상 처리 및 AI 관련 도구

다음은 영상 처리와 AI 분석에 사용된 주요 라이브러리입니다.

먼저 OpenCV는 카메라나 영상 파일에서 프레임을 가져오고, AI 모델에 전달할 수 있는 형태로 처리하는 역할을 합니다.
YOLO는 영상 안에서 사람을 탐지하는 데 사용했고, BoT-SORT는 YOLO가 탐지한 사람에게 Track ID를 부여하여 같은 사람의 이동을 계속 추적하도록 사용했습니다.
InsightFace는 사람의 얼굴에서 특징값을 추출하고, 미리 등록된 대상자 얼굴과 비교하는 역할을 합니다.
Torch와 ONNX Runtime은 이러한 AI 모델이 실제로 연산되고 실행될 수 있도록 지원합니다.
여기서 모든 라이브러리를 하나씩 설명하기보다는, 핵심적으로는 영상 입력, 사람 탐지, 사람 추적, 얼굴 식별의 네 단계로 구성되어 있다고 이해하시면 됩니다.
AI·영상 처리에는 OpenCV, Ultralytics, InsightFace, ONNX Runtime과 Torch가 사용되었습니다.

4. 데이터 저장 및 보조 도구

다음은 데이터 저장과 시스템 운영에 사용된 도구입니다.

저희 프로젝트는 별도의 데이터베이스 서버를 구축하지 않고, 계정 정보, 대상자 정보, 탐지 로그 등의 데이터를 JSON 파일로 관리했습니다.
얼굴 데이터는 일반 이미지 자체를 비교하는 것이 아니라, 얼굴에서 추출한 숫자 형태의 특징 벡터를 NPZ 파일로 저장하여 비교했습니다.
또한 requests와 PyYAML은 통신과 설정 파일 처리에 사용했고, psutil은 시스템 상태를 확인하는 데 활용했습니다.
Pandas와 OpenPyXL은 표 형태의 데이터를 처리하거나 엑셀 파일과 연결할 때 사용할 수 있도록 구성했습니다.
정리하면, 일반적인 시스템 정보는 JSON으로 관리하고, 얼굴 인식에 필요한 수치 데이터는 NPZ로 분리하여 관리했습니다.
