현재:

이 부분은 문제가 없습니다.

즉, 이전에 예상했던:

같은 HTML 중복 삽입 문제는 아닙니다.

현재 발생하는:

의 원인은 다른 곳입니다.

가장 가능성이 높은 원인은 SSE 연결을 생성하는 코드가 여러 번 실행되는 것입니다.

원인 후보 1: window.addEventListener("load") 중복 실행

현재 코드:

window.addEventListener("load", function () {

    const firstEventId = document.querySelector(".event_id");

    if (firstEventId) {
        lastLogId = firstEventId.innerText.trim();
    }

    connectSSE();
});

문제는:

logger_alarm.js 자체가 1번 로드되어도,

다른 JS에서 같은 함수를 호출하거나 페이지 이동 과정에서 script가 재평가되면 연결이 다시 생성될 수 있습니다.

우선 수정할 부분
1. 기존 코드
window.addEventListener("load", function () {

    const firstEventId = document.querySelector(".event_id");

    if (firstEventId) {
        lastLogId = firstEventId.innerText.trim();
    }

    connectSSE();
});
변경
window.addEventListener("load", function () {


    const firstEventId =
        document.querySelector(".event_id");


    if(firstEventId){

        lastLogId =
            firstEventId.innerText.trim();

    }


    if(!window.eventSource){

        connectSSE();

    }

});
원인 후보 2: window.eventSource 초기화 위치 문제

현재 수정한 코드가 만약:

let source = null;

과 같이 남아있으면 효과가 없습니다.

반드시 삭제:

let source = null;

그리고 최상단:

if(!window.eventSource){

    window.eventSource = null;

}

로 변경합니다.

최종 형태

파일 최상단:

    window.eventSource = null;
